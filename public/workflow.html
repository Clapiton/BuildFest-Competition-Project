AI Complaint Pipeline Architecture

10Alytics Business BuildFest 2026 — Track 5: AI Automation & Integrations (Participant ID: BF-1079)

1
🌐
Customer Submits Complaint
Web Intake Form → POST /api/complaints · Zod input validation (400 response on empty)
2
🧠
AI Extraction & Classification
OpenAI / Claude API → category · urgency · sentiment · 1-sentence summary · empathetic draft reply
3
🔀
Route to Category Owner
Billing → alice@support.team · Product → bob@support.team · Service → carol@support.team
4
📧
Send Automated Notifications
Customer acknowledgment + team member assignment alert via Resend / SMTP
5
🗄️
Persist Record & Audit Trail
Supabase Postgres DB · Status transitions: received → in_progress
6
⏱️
Schedule Delayed Escalation Timer
BullMQ delayed queue on Upstash Redis · 3 mins (demo) / 24h (production SLA)
7
🚨
Auto-Escalate SLA if Unresolved
Reassign to manager@support.team · Status → escalated · Escalation alert sent
Or Resolved Before SLA Timer Expires
✅
Human Agent Resolves Complaint
POST /api/complaints/:id/resolve → Status: resolved · Delayed escalation job removed from Redis

📜 Audit State Machine

received
Complaint stored in Supabase Postgres DB
classified
AI extracted category, urgency & sentiment
assigned
Routed to category owner
notified
Customer ACK & staff alert dispatched
timer_set
BullMQ delayed escalation enqueued
escalated
SLA timed out → reassigned to Manager
resolved
Agent resolved case → SLA timer cancelled
